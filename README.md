# SMS Spam Classifier

An NLP-based machine learning project that classifies SMS messages as spam or legitimate.

## Features

- Text preprocessing using NLTK
- TF-IDF feature extraction
- Multinomial Naive Bayes classification
- Streamlit web interface
- Trained model and vectorizer saved using Pickle

## Tech Stack

- Python
- Pandas
- NLTK
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes
- Streamlit

## How It Works

1. User enters an SMS message.
2. The message is preprocessed using NLTK.
3. The text is converted into TF-IDF features.
4. The trained Multinomial Naive Bayes model predicts whether the message is spam or legitimate.
5. The result is displayed through the Streamlit interface.
